### B1

Скрипт `clean_old_logs.sh` принимает два аргумента: путь к директории с логами и количество дней **N**.
При запуске он ищет все `.log` файлы, которые старше **N** дней, выводит их список и запрашивает подтверждение перед удалением.

Количество дней передаётся вторым аргументом и используется в команде `find` через параметр `-mtime +N`.

Пример запуска:

```bash
./clean_old_logs.sh /var/log 30
```

В этом примере будут найдены и предложены к удалению `.log` файлы старше 30 дней.
