### B2

Если в рабочей ветке есть незакоммиченные изменения, а нужно временно перейти в `main`, удобнее всего использовать `git stash`.

Сначала сохраняем изменения:

```bash
git stash push -u
```

Переходим в ветку `main`, выполняем нужные действия и возвращаемся обратно:

```bash
git switch main
git switch -
```

После возвращения восстанавливаем изменения:

```bash
git stash pop
```

Если нужно переименовать последний коммит, это можно сделать командой:

```bash
git commit --amend -m "New commit message"
```

Если коммит уже был отправлен в удалённый репозиторий, после этого потребуется `git push --force-with-lease`.
